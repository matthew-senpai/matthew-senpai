## 🧠 About Me

I'm an Electronics and Communication Engineering student at **Velammal Engineering College**, building at the intersection of **embedded systems, AI/ML, and full-stack software**. My work spans acoustic-signal ML on microcontrollers, RF/antenna research aimed at Scopus-indexed publication, AI-driven healthcare screening tools, and portfolio-grade software projects built for hackathons and technical assessments.

I care about shipping things that actually run on real constraints — a quantized model that fits on an STM32, an antenna design that survives VNA measurement, a pitch that survives a judging panel. I build complete, working projects end-to-end rather than stopping at prototypes, and I'm adaptable, detail-oriented, and eager to keep growing as an engineer.

## 🚀 Featured Projects

<details>
<summary><b>🌊 HYDRASHIELD-EDGE — Acoustic Cavitation Detection</b></summary>
<br/>

Acoustic-emission based cavitation detection for hydraulic machinery, developed for **Tata InnoVent 2027**. Runs entirely at the edge on an STM32 + FreeRTOS stack, using an INT8-quantized ML model to classify cavitation signatures from acoustic sensor data over a J1939 CAN bus.

| | |
|---|---|
| **Stack** | STM32 · FreeRTOS · INT8-Quantized ML · J1939 CAN Bus · STM32Cube.AI |
| **Scale** | Single-MCU edge deployment with a hardware-free simulation pipeline (STM32Cube.AI, Renode, python-can) for pre-hardware validation |
| **Performance** | Validated against the MIMII industrial acoustic benchmark dataset |
| **Security** | Local CAN-bus telemetry only — no external network exposure |
| **Impact** | Early cavitation detection aimed at preventing hydraulic-machinery damage and unplanned downtime |
| **Repository** | [github.com/matthew-senpai/hydrashield-edge](https://github.com/matthew-senpai/hydrashield-edge) |

Built for a machinery-health context where false positives are costly and compute is scarce — the emphasis throughout was validating the model against a real benchmark and proving the pipeline works without needing the physical rig on hand.

</details>
